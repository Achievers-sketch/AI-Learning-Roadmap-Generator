# 🧠 AI Learning Roadmap Generator

An AI-powered application that generates personalized learning
roadmaps based on a user's learning domain, skill level,
available time, and learning goals.

## 🚀 Features

- Personalized learning roadmaps
- Beginner, Intermediate, and Advanced levels
- Weekly learning schedules
- Practical projects
- Learning resources
- Milestones and assessments
- AI-generated capstone projects

## 🛠️ Technologies

- Python
- Gradio
- Groq API
- Large Language Model
- Hugging Face Spaces

## 💻 How It Works

1. Enter the domain you want to learn.
2. Select your current skill level.
3. Select your learning duration.
4. Specify your available hours per week.
5. Enter your learning goal.
6. Click **Generate Roadmap**.
7. The AI generates a personalized roadmap.
